# Fairytale App — High-Level Design

## Functional Requirements

1. **Story Creation** — User creates a story with 4 inputs:
   - Phonics level
   - Character
   - Theme
   - One-sentence story plot

2. **Story Library** — User can browse a list of stories they have created.

3. **Story Review** — User can review a generated story and accept it before showing it to their child.

## Non-Functional Requirements

1. Story is generated by LLM.
2. Each story has **one image per sentence**.
3. When generation is complete, the system sends a **push notification** (simplified to client poll-based for now).
4. The system has a **monthly payment system**.
5. **4 credits per month** are issued upon renewal.

---

## Entities

| Entity | Fields |
|---|---|
| **User** | userId, stories[] |
| **StoryConfig** | 4 inputs, status (`pending` / `accepted` / `reported`), storyId |
| **Story** | sentence, picture (blob link) |
| **PhonicWords** | level, word |

---

## System Architecture

```
Client → Load Balancer → Server → Queue → Story Creation Worker
                           ↓
          ┌────────────────┼──────────────────────┐
          ↓                ↓                      ↓
   PhonicWords DB    StoryConfig DB           User DB
                     (4 inputs, status,      (userId, stories[])
                      storyId, title,
                      userId, createdAt)
                                         Story DB    Blob Storage
                                         (storyId,   (picture)
                                          blobLink,
                                          content,
                                          userId)
```

## API Design

### 0. Authentication
All endpoints require user credential.

---

### 1. `POST /stories/create`
**Request:** user credential
```json
{
  "phonicsLevel": "...",
  "character": "...",
  "theme": "...",
  "prompt": "..."
}
```
**Response:** `200 / 400 / 500`

---

### 2. `GET /stories`
**Request:** user credential

**Response:** `List<Story>` with fields:
- theme
- phonics level
- title
- createdAt
- lastViewed

---

### 3. `GET /stories/{storyId}`
**Request:** user credential

**Response:**
- story (text sentences)
- blob links (images)

---

### 4. `PUT /stories/{storyId}` *(accept/reject)*
**Request:** user credential
```json
{
  "userId": "...",
  "storyId": "...",
  "status": "(accept/reject)"
}
```
**Response:** `200 / 400 / 500`
